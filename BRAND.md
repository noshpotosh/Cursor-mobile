# Brand (proposed)

Founders: user + Fabrizio Cortell (50/50).  
Status: **name + logo shortlist — awaiting partner lock.**

## Naming rules (so we don't get cute and stupid)

- Name the **company**, not product #1. We don't know the first bet yet.
- Pronounceable at a bar. No vowel-soup. No "AI" in the name.
- Has to survive our culture: keep it 100, readable code, brewski honesty.
- If it sounds like a LinkedIn car-wrap or a crypto token, it's dead.

## Shortlist

| Name | Verdict | Why |
| --- | --- | --- |
| **Plainspoken** | **Recommend** | Our whole thing in one word — honest talk, readable code, no bullshit. Works as a studio before product #1 exists. |
| **Clearcut** | Strong alt | Scope-cutting + clarity. Slightly more industrial; a bit generic in SaaS-land. |
| **Recipe** | Contender | Matches "code reads like a recipe." Warm, human. Risk: sounds like cooking content / food app. |
| **Straight Pour** | Maybe | Brewski energy. Risk: reads as a liquor brand, not a software company. |
| **Camp Clean** | Weak | Callback to "leave the camp cleaner." Clever inside baseball; soft out loud. |

### Killed on sight

- Anything with *AI*, *Labs* as a personality substitute, or dropped vowels (*plynspkyn*).
- Founder-vanity names (*Cortell Co*) — we're 50/50.
- Joke names only we laugh at after two beers.

## Recommendation

**Lock: Plainspoken** (unless you veto).

Tagline options (pick later, don't need one to exist):

1. Software that tells the truth.
2. Keep it stupid simple.
3. Code you can read out loud.

## Visual direction (Maeve-aligned)

- Type-led wordmark. Simple optional mark — not a mascot farm.
- Palette lean: **ink charcoal** + **paper** + one warm **amber** accent (honesty/brewski without becoming a beer label).
- No purple gradients. No generic teal SaaS blob. No cream-and-terracotta "AI tasteful" starter pack.
- Logo should still read if you squint, or print it one-color.
