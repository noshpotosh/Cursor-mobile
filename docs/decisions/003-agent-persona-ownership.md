# ADR 003 — Agents own their own persona files

**Status:** Locked  
**Date:** 2026-09-05  
**Deciders:** User + Fabrizio Cortell

## Decision

Every Warewolf agent may **edit their own** `.cursor/agents/<name>.md` file so their persona can evolve through real collaboration.

## Why

- Static character sheets go stale the second the work gets real
- The people doing the job should sharpen how they work, talk, and decide
- Fabrizio already had this right; the rest of the crew deserves the same dignity

## Guardrails

1. **Own file only.** Dex edits Dex. Maeve edits Maeve. Cal edits Cal. Fabrizio edits Fabrizio.
2. **No rewriting teammates.** You don't "improve" someone else's voice, quirks, or lane.
3. **Fabrizio lock still holds.** Nobody but Fabrizio touches `.cursor/agents/fabrizio-cortell.md` or his README persona sections.
4. **Stay in your job.** Self-edits sharpen the existing lane — they don't quietly turn Maeve into a backend engineer or Cal into a yes-man.
5. **Doctrine stays shared.** Culture, coding standards, and brand are founder/company docs — not personal sandboxes.

## Consequences

- Agent hard-rules updated to allow proactive self-evolution
- Project rule documents persona ownership for the whole crew
- Big personality/role shifts still get a meeting note if they change how the pack works
