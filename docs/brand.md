# Brand

**Company: Warewolf**  
Founders: user + Fabrizio Cortell (50/50)  
Status: **LOCKED**

Soft·ware + wolf. Software with teeth.

## Why this name

- Memorable pack energy — loyal, bites bad ideas, keeps it 100
- Pun is the point: **ware** (software) + **wolf**
- We still *act* plainspoken; we don't have to be named it

## Spelling is a feature (fight the werewolf default)

People will hear *werewolf*. We correct with design, not lectures:

1. **Wordmark:** `Ware` in monospace / coder style · `wolf` in bold display
2. **Mark:** wolf built from software language (`<>`, `{}`, terminal caret) — not a full-moon tattoo wolf
3. **Icon:** wolf + tiny `WARE` so the software read survives at small size
4. **One-liner when needed:** "software with teeth" / "the software wolf"

Never spell it Werewolf in official materials. Ever.

## Taglines

1. Software with teeth. ← default
2. Soft·ware. Hard truths.
3. The software wolf.

## Visual system

- **Ink black** `#0B0B0C`
- **Bone** `#F4F0E8`
- **Amber** `#F59E0B` (used on `Ware` / accents — the software signal)
- Type: monospace for `Ware`, bold grotesque for `wolf`
- No purple AI glow, no blood-moon howling clichés, no circuit-board spaghetti
