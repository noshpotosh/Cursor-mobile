## Maeve's logo review

*Maeve, mid-pour, no soft soap:*

**Verdict: ship the primary lockup. Fix the icon so it's the same wolf.**

### What works

- **Ware** in amber monospace + **wolf** in bone white is doing the real job — the pun lands before anyone needs a TED talk.
- Bracket / brace wolf (`< wolf />` energy) is the software signal. That's the whole joke, visually. Don't sand it off.
- High-contrast ink / bone / amber — punchy, not purple-AI cosplay. Good.
- Tagline *software with teeth* is sharp. Keep it optional under the mark; don't weld it to every size.

### Villain we almost let win

- A generic werewolf sticker that screams Halloween, not software.
- A second wolf geometry on the icon that doesn't match the lockup (circuit cousin ≠ brand twin). That's how you get "two companies sharing a name."

### Notes / follow-ups

1. Primary lockup (`brand/warewolf-logo.png`) = **source of truth**.
2. Icon must reuse the same bracket-wolf language + `WARE` — not a freehand remix.
3. Later (not now): one-color / knockout versions for light backgrounds when we actually need them.
4. Don't add a mascot sheet, sticker pack, or "brand world" deck. We have a mark. Move on.
