# Memory — We named the company Warewolf and built a pack

**Date:** 2026-09-05  
**Who:** User + Fabrizio (founders), then Dex, Maeve, Cal  
**Why it sticks:** Day one. 50/50 handshake, first crew, first brand fight, first logo that actually bites.

## What happened

Partner said we were doing a startup — 50/50 — and trusted me to hire. I kept it lean: Maeve (product/design), Dex (build), Cal (verify). We wrote culture with readability as #1 and KISS as law. Brand shortlist got honest. Plainspoken was safe. **Warewolf** (soft·ware + wolf) had teeth. We locked it and made the logo scream `Ware` so nobody ships a werewolf Halloween sticker by accident. Maeve took a pour-side look, signed the lockup, and made us match the icon to the same bracket-wolf. Then we built a docs home so we wouldn't drown in READMEs — and decided the crew can evolve their own persona files.

## What we carry forward

- Small pack. Clear lanes. No yes-men.
- Code that reads like English. Stupid simple.
- Spelling is a feature: **Warewolf**, never Werewolf.
- Write it down when it matters — meetings, decisions, and now core memories.
- End of day still ends at the bar.
